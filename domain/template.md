## 📝 Domain Analysis Note Structure

This template is automatically populated by the overnight research engine when creating new domain analysis notes in Tolaria.

### Required Frontmatter Fields:

| Field | Description | Example Values |
|-------|-------------|----------------|
| type | Note category | `domain-analysis` |
| domain_name | Domain identifier | `political`, `military`, `religious`, `geographic` |
| name | Full domain name | `Political Domain`, `Military Domain` |
| core_symbols | Array of core symbols tracked | `[124, 666]` |
| elemental_forces | Forces appearing in this domain | `[fire]` |
| confidence_score | Pattern confidence for this domain | `0.85` |
| created | Timestamp | `"2026-04-29"` |
| last_modified | Last update timestamp | `"2026-04-29T01:45:06"` |
| tags | Categorization tags | `[domain, political, analysis]` |
| wikilinks | Related symbol/domain notes | `[[CORE_SYMBOL_124]]`, `[[DOMAIN_MILITARY]]` |

### Optional Fields:

| Field | Description | Example Values |
|-------|-------------|----------------|
| pattern_frequency | How often this domain appears | `high`, `medium`, `low` |
| primary_elemental | Dominant elemental force | `fire`, `air`, `water` |
| transformation_cycles | Cycle patterns observed | `[963, 124]` |
