## Conflict Escalation Pattern Analysis

### Pattern H1: Economic → Political → Military

```
Sequence Documented in Sahel (2024):

Stage 1: French aid cuts announced (Economic weakening)
    ↓
Stage 2: Currency devaluations begin (Naira, CFA franc pressure)
    ↓  
Stage 3: Protest movements emerge (Political instability)
    ↓
Stage 4: Military coups occur (Mali Feb 2024, Burkina Faso Sep 2024)
    ↓
Stage 5: New alliances form (EMIRNA → Wagner alignment)
```

### Pattern H2: External Intervention Cycle

```
Phase A: Proxy conflict begins (US/Russia/Iran/China competition)
Phase B: Local partner becomes dependent on external patron
Phase C: Patron increases influence via military/economic aid  
Phase D: Local partner gains autonomy from primary patron
Phase E: Internal fracture emerges between factions
```
