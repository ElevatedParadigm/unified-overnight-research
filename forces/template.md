## 📝 Elemental Force Note Structure

This template is automatically populated by the overnight research engine when creating new elemental force notes in Tolaria.

### Required Frontmatter Fields:

| Field | Description | Example Values |
|-------|-------------|----------------|
| type | Note category | `elemental-force` |
| force_name | Force identifier | `fire`, `earth`, `air`, `water`, `lightning` |
| name | Full force name with icon | `🔥 Fire Force`, `⚡ Lightning Force` |
| description | Short elemental characteristic | `"Rapid transformation, burning, purification"` |
| characteristics | Array of key traits | `[instantaneous, chain-reaction, disruptive]` |
| correlates_to | Core symbols this relates to | `[124, 777]` |
| complements | Forces that work with this one | `[lightning, oxygen]` |
| created | Timestamp | `"2026-04-29"` |
| tags | Categorization tags | `[elemental, fire, transformation]` |
| wikilinks | Related force/symbol notes | `[[ELEMENTAL_FORCE_LIGHTNING]]`, `[[CORE_SYMBOL_124]]` |
